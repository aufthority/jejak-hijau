GHG Protocol alignment
Two-tier model — Group benchmark reconciled against KPJU's own bottom-up data.
Tier 1 — Group benchmark
Reference only

KPJ Group's reported bed-day emissions intensity and GET (Green Electricity Tariff) enrolment precedent — used as methodological reference, not extrapolated into KPJU's own figures.

Tier 2 — KPJU bottom-up data
Scope 2 · dual method

kWh/student from Finance billing, converted to tCO₂e using Malaysia's grid emission factor. Reported both location-based (grid average) and market-based (accounting for GET, if applicable), per GHG Protocol Scope 2 Guidance.

Scope 1 — direct emissions
Scoped for future version

Backup generators, refrigerant leaks, any owned vehicles or on-site combustion. Likely small relative to Scope 2, and needs facilities records not yet gathered — assessed, not measured, in this version.

Scope 3 — paper waste
Volume metric, not converted

Sheets/student is reported as a waste-volume figure only. Converting to an emissions estimate would need supply-chain data KPJU doesn't have — kept honest rather than precise-looking.
